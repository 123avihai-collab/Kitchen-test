# חיבור "שמור ושלח" ל-Google Drive (פעם אחת, כ-5 דקות)

אחרי ההתקנה, כל מי שלוחץ באתר על **שליחת התכנון ← שמור ושלח**:
- נשמר אצלך ב-Drive, בתיקייה "הגשות – מטבח תלת-ממדי": קובץ התכנון וצילום מסך.
- נוספת שורה בגיליון: תאריך, שם, טלפון, הערה, קישור **"פתח בכלי"** וצילום.
- נשלח אליך מייל עם הצילום וכפתור פתיחה.

## שלבים
1. פותחים גיליון חדש: https://sheets.new ונותנים לו שם, למשל "הגשות מטבח".
2. בתפריט: **הרחבות ← Apps Script**.
3. מוחקים את מה שכתוב בעורך ומדביקים את כל התוכן של `Code.gs` מהתיקייה הזו. שומרים (Ctrl+S).
4. בוחרים למעלה את הפונקציה **setup** ולוחצים **הפעלה (Run)**. מאשרים הרשאות:
   Review permissions ← בוחרים את החשבון ← Advanced ← Go to … (unsafe) ← Allow.
   (האזהרה מופיעה כי זה סקריפט פרטי שלך ולא אפליקציה מאומתת.)
5. **פריסה (Deploy) ← פריסה חדשה (New deployment)**. ליד Select type בוחרים ⚙ **Web app**:
   - Execute as: **Me**
   - Who has access: **Anyone**
   - Deploy, ואז מעתיקים את ה-**Web app URL** (מסתיים ב-`/exec`).
6. מדביקים את הכתובת ב-`js/config.js`, בשדה `SUBMIT_URL`, או שולחים אותה ל-Claude שיעדכן.

## הערות
- הכתובת לא סודית, כי היא מוטמעת באתר הציבורי. מי שיודע אותה יכול לשלוח הגשה, אבל לא לראות את ההגשות האחרות. התכנונים נשמרים רק ב-Drive שלך.
- כדי לשנות מייל להתראה או לבטל אותה: `NOTIFY_EMAIL` בראש הקוד.
- אחרי שינוי בקוד צריך לפרוס מחדש: Deploy ← Manage deployments ← ✏ ← Version: New version. כך הכתובת נשארת אותה כתובת.
