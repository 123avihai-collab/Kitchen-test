# מטבח תלת-ממדי – ניסוי

ניסוי של מטבח תלת-ממדי מציאותי שרץ בדפדפן (גם בטלפון), עם כלי עריכה אינטראקטיבי בעברית.
אתר סטטי (Three.js) – בלי שרת ובלי בסיס נתונים. התכנון נשמר בדפדפן, ואפשר לייצא ולייבא אותו כקובץ JSON.

## הפעלה מקומית
```bash
python3 -m http.server 8000
```
ואז לפתוח את http://localhost:8000

## פרסום ב-GitHub Pages
Settings → Pages → Build and deployment → Source: **Deploy from a branch** → בוחרים ענף ותיקייה `/ (root)` → Save.
אין שלב בנייה (build): כל הקבצים, כולל three.js, נמצאים בריפו.

## שיתוף ואיסוף תכנונים
- כפתור **"שליחת התכנון"** יוצר קישור שהתכנון מקודד בתוכו (וואטסאפ, העתקה, שיתוף).
- **"שמור ושלח"** שומר את התכנון וצילום מסך ב-Google Drive של בעל האתר, מוסיף שורה בגיליון ושולח מייל. הוראות התקנה: [`apps-script/README.md`](apps-script/README.md). אחרי ההתקנה מעדכנים את `SUBMIT_URL` ב-`js/config.js`.

## מבנה הקוד
| קובץ | תפקיד |
|---|---|
| `index.html`, `css/style.css` | ממשק: סרגל כלים, פאנל צד/גיליון תחתון, ג׳ויסטיק |
| `js/main.js` | רנדרר, HDRI, Ambient Occlusion (GTAO), לולאת רינדור לפי דרישה, קלט |
| `js/state.js` | מצב התכנון, ברירות מחדל, שמירה בדפדפן, ביטול/חזרה, ייצוא/ייבוא |
| `js/room.js` | חדר, חלון אופקי בקיר הימני, נוף, תאורה (שמש, ספוטים) |
| `js/cabinets.js` | ארונות תחתונים/עליונים/טורים, משטחים, חיפוי, LED, אי וכיסאות |
| `js/appliances.js` | מקרר דו-דלתי, תנור, מיקרוגל, כיריים, קולט אדים, מדיח, כיור, ברז, כיסא, מנורה |
| `js/materials.js` | ספריית חומרים PBR וטקסטורות |
| `js/interaction.js` | בחירה, פתיחה/סגירה באנימציה, מסגרת בחירה |
| `js/controls.js` | סיבוב סביב החדר והליכה בגובה עיניים (מקלדת/ג׳ויסטיק) |
| `js/measure.js` | כלי מדידה וקווי מידות |
| `js/editor.js` | פאנל העריכה |
| `js/share.js`, `js/config.js` | שיתוף בקישור ושליחה ל-Drive |
| `apps-script/Code.gs` | הסקריפט שקולט הגשות ב-Google Drive |

## מערכת צירים ויחידות
מטרים. קיר המטבח ב-z=0, החדר נמשך לכיוון ‎+z. ‏x=0 במרכז קיר המטבח, ‎+x = ימין למי שמסתכל על הקיר (צד החלון).
